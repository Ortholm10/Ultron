Ultron
What it is Before you start Install Troubleshooting

Your own AI agent, running on your own Windows PC.

Ultron gives Claude Code a memory vault, a push-to-talk voice, a live face, and optional hand tracking. Everything runs on your computer, and your notes stay in your own folder.

Start the install View the code on GitHub

What you get

Four parts that work together. The first two are the core. The face and hands are extras you can add.

  • Memory
    An Obsidian vault
    Plain-text notes that the agent reads at the start of every chat and updates as you work.
  • Voice
    Push-to-talk
    Hold one key, speak, and release. The agent answers out loud with a local voice.
  • Face
    A live visualizer
    A browser page that shows whether the agent is idle, listening, thinking, or speaking.
  • Hands
    Hand tracking, optional
    Move notes and images on screen with your hands, using your webcam.

Before you start

Check these first. The voice and hands use your own microphone and webcam, so they only work on the computer where you install them.

  • Windows 10 or Windows 11
  • A paid Claude plan. Pro works. Free accounts do not include Claude Code.
  • About 3 GB of free disk space, for Python packages and speech models
  • A microphone and speakers for the voice
  • A webcam and Google Chrome, only if you want the hands

Install, step by step

Run each step in order. Most steps are one command. Restart PowerShell after step 1 so the new tools are on your PATH.

  1. 01

    Install the tools

    Open PowerShell and run these four lines.

    winget install --id Git.Git -e
winget install --id Obsidian.Obsidian -e
winget install --id eSpeak-NG.eSpeak-NG -e
irm https://astral.sh/uv/install.ps1 | iex
  2. 02

    Install Claude Code and sign in

    Get Claude Code from claude.com/claude-code. Then run claude in any terminal, choose Claude account with subscription, and log in when your browser opens.

  3. 03

    Copy the Ultron components into one folder

    This creates a folder called my-agent on your Desktop and copies the parts into it.

    mkdir $HOME\Desktop\my-agent
git clone https://github.com/Ortholm10/Ultron.git $HOME\Desktop\ultron-clone
Copy-Item -Recurse $HOME\Desktop\ultron-clone\ultron-agent\* $HOME\Desktop\my-agent\
  4. 04

    Create your memory vault

    In Obsidian, choose Create new vault and name it, for example Ultron Brain. Put it in your user folder, not in OneDrive or Documents. Then open my-agent in Claude Code and say:

    read ai-memory-vault\ai-memory-vault.md and set me up

    Answer its questions. It builds the vault and writes your CLAUDE.md.

  5. 05

    Configure the voice

    In backtalk, copy backtalk.json.example to backtalk.json. Set agent_dir to your my-agent folder, name to your agent's name, extra_dirs to your vault, and ptt_key to the key you hold to talk. Set permission_mode to "ask" so it checks before it acts.

  6. 06

    Install the voice engine and speech models

    This downloads about 1 GB on the first run only.

    cd $HOME\Desktop\my-agent\backtalk
$uv = "$HOME\.local\bin\uv.exe"
& $uv venv .venv
& $uv pip install --python .venv\Scripts\python.exe -e .
  7. 07

    Configure the face

    In ai-visualizer, copy ai-visualizer.json.example to ai-visualizer.json. Set name to your agent's name and bus_dir to the full path of your backtalk folder.

  8. 08

    Configure the hands, optional

    In barehands, copy barehands.json.example to barehands.json. Set name and point the Notes folder at your vault.

  9. 09

    Create three Desktop launchers

    Save these as .bat files on your Desktop. Replace <you> with your Windows user name.

    Chat with Ultron.bat
  cd /d "C:\Users\<you>\Desktop\my-agent"
  claude

Talk to Ultron.bat
  call "C:\Users\<you>\Desktop\my-agent\fullstack-agent\start.bat" voice

Ultron barehands.bat
  call "C:\Users\<you>\Desktop\my-agent\fullstack-agent\start.bat" hands
  10. 10

    Test it

    Double-click Talk to Ultron. A console window opens, the voice loads, and the face opens in your browser. Hold your talk key, speak, and release. The agent answers out loud.

If something goes wrong

These are the problems people hit most often.

Nothing happens when I hold the talk key Click the console window once so it has focus. Check that ptt_key in backtalk.json matches a key your keyboard has, then restart the window.
The console shows a cublas64_12.dll warning It is harmless. Add "stt_device": "cpu" to backtalk.json to skip the check.
The hands page is black or the ring does not move Open the page in Chrome, allow camera access, and close any other app that uses the webcam, such as Zoom or Teams.
The face does not open Open http://127.0.0.1:8790/faces/board/ in your browser. If that page loads, the face works, and the launcher just did not open it.
